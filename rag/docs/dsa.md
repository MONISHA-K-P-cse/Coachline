# Data Structures and Algorithms

## Arrays
- Store elements in contiguous memory.
- Access time: O(1)
- Insertion at end: O(1)
- Insertion at beginning: O(n)

## Linked Lists
- Dynamic memory allocation.
- Insertion: O(1)
- Searching: O(n)

## Stacks
- LIFO (Last In First Out)
- Operations:
  - Push
  - Pop
  - Peek

## Queues
- FIFO (First In First Out)
- Operations:
  - Enqueue
  - Dequeue

## Trees
- Binary Tree
- Binary Search Tree
- AVL Tree

## Graphs
- BFS
- DFS
- Dijkstra
- Topological Sort

## Sorting Algorithms

Bubble Sort
Time Complexity:
O(n²)

Merge Sort
Time Complexity:
O(n log n)

Quick Sort
Average:
O(n log n)

Worst:
O(n²)

## Dynamic Programming

Used for optimization problems.

Examples:
- Knapsack
- Longest Common Subsequence
- Matrix Chain Multiplication
