# Machine Learning & AI Engineering

Interview preparation reference for AI Engineer, ML Engineer, AIML Engineer,
Machine Learning Engineer, Applied Scientist, and Data Scientist roles.
This is an artificial intelligence and machine learning topic area, distinct
from general software/backend/systems engineering topics.

## Core ML Workflow
- Data collection and cleaning
- Feature engineering and selection
- Train/validation/test split
- Model training and hyperparameter tuning
- Evaluation and error analysis
- Deployment and monitoring (data drift, model decay)

## Supervised Learning
- Regression (linear, logistic) vs classification
- Bias-variance tradeoff, overfitting vs underfitting
- Regularization: L1 (Lasso), L2 (Ridge), dropout

## Unsupervised & Self-Supervised Learning
- Clustering: k-means, hierarchical clustering, DBSCAN
- Dimensionality reduction: PCA, t-SNE, UMAP
- Anomaly detection
- Self-supervised pretraining objectives (masked language modeling, contrastive learning)

## Reinforcement Learning Basics
- Agent, environment, reward, policy, value function
- Exploration vs exploitation
- Q-learning, policy gradients (high level)

## Model Evaluation
- Classification: accuracy, precision, recall, F1, ROC-AUC, confusion matrix
- Regression: MSE, RMSE, MAE, R²
- Cross-validation

## Neural Networks & Deep Learning
- Perceptron, activation functions (ReLU, sigmoid, softmax)
- Backpropagation and gradient descent (SGD, Adam)
- Convolutional Neural Networks (CNNs): filters, pooling, feature maps - used for image/spatial data
- Recurrent Neural Networks (RNNs), LSTM, GRU - used for sequential data
- Transformers and attention mechanisms - used for language and sequence modeling
- Vanishing/exploding gradients, batch normalization

## Natural Language Processing
- Tokenization, embeddings (word2vec, GloVe, contextual embeddings)
- Sequence-to-sequence models, attention
- Large Language Models: pretraining, fine-tuning, prompting, RAG

## MLOps & Production ML
- Model versioning and experiment tracking
- Feature stores
- A/B testing for model rollout
- Monitoring for data/concept drift
- Latency vs accuracy tradeoffs at inference time

## Common Interview Topics
- Explain a project end-to-end (problem framing, data, model choice, evaluation, impact)
- Trade-offs between model complexity and interpretability
- How to handle imbalanced datasets
- How to detect and address overfitting
